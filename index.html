Your coding agents, on every machine you own.

GOAT runs the agents you already use, like Claude Code, Codex and Cursor, on your laptop, a desktop at home, an SSH server or a cloud machine. Steer all of them from the desktop app, a browser or your phone.

Free and open source under the MIT license, for macOS, Windows and Linux.

Every machine is an environment

Each machine you work on runs a GOAT server. That server and the state it owns (projects, threads, provider sign-ins and memory) form an environment. The desktop app, a browser or your phone can connect to as many environments as you like, and an environment can reach others.

Remote access guide
SSH hosts
Add a host in Settings → Connections. It downloads its own GOAT runtime on first use. Boat cloud machines work like any other SSH host.
Linked GOAT servers
Link a GOAT server you already run with a pairing link, so agents can start, read and message threads there.
WSL
On Windows, a WSL distro runs its own environment with the provider CLIs installed inside it.
Your other screens
Pair a phone or another browser directly, over your local network, or over Tailscale.

Start on one machine, finish on another

Agents in GOAT can cross machines, and so can your work.

  1. Start a thread on your laptop

    Pick a project and a provider. When the agent works in a local Git checkout, each turn saves a checkpoint, so you can review exactly what it changed and restore it.

  2. Move it to a bigger machine

    Move a thread to an SSH host with its uncommitted changes, or let an agent start a thread or worktree there and wait for the result.

  3. Follow it from anywhere

    Open the same thread from your phone or another browser paired with that environment, and answer when it needs you.

  4. Bring the branch back

    Fetch the branch from an SSH worktree into the repository on this device. Your current branch and working files stay as they are.

What GOAT adds

  • GOAT Bot

    One standing conversation that is not tied to a project. Ask it for work and it starts a coding thread in the right project and machine, then reports back. It also answers in Slack, and over iMessage when the server runs on a Mac.

    Read the guide: GOAT Bot

  • Fleet

    One view of every connected machine and the agents working on it, with counts of threads that are running or waiting for you. Fleet goals keep starting workers until the conditions you set hold.

    Read the guide: Fleet

  • Memory

    Finished conversations become memories scoped to all projects, one project or one thread. Import memories from Codex, Claude and OMO, and share them between devices through a hub.

    Read the guide: Memory

  • Orchestration tools

    The GOAT MCP server gives agents tools to launch threads, watch them and report results to the thread that started them. Outside agents such as Claude Code, Codex and ChatGPT can connect to the same server.

    Read the guide: Orchestration tools

  • Computer, browser and devices

    Agents can use apps on the computer that runs GOAT without taking over your cursor. The desktop app has a browser panel beside each thread, and a Device panel shows an iOS Simulator or Android Emulator an agent can drive.

    Read the guide: Computer, browser and devices

  • Source control and pull requests

    Clone and publish repositories, open pull requests and review each turn's own changes. GitHub, GitLab, Forgejo, Gitea, Bitbucket, Azure DevOps and GitCafe are supported.

    Read the guide: Source control and pull requests

  • Visual replies

    Ask for a chart, a table or a diagram and the agent answers with a sandboxed page in the thread. It works with every provider, on web, desktop and mobile.

    Read the guide: Visual replies

Open source, built in public

GOAT is MIT licensed and developed in a public repository, with its work tracked in GitHub issues and pull requests. It began as a fork of T3 Code, keeps its event-sourced core, and still merges upstream changes.

Install GOAT

The desktop app updates itself. The goat install script follows the Nightly train unless you set GOAT_CHANNEL=stable.

Desktop app

For macOS, Windows and Linux. It includes the server and the goat command, so it can also host the environment your other screens connect to.

Choose a download

The goat command

Starts the server and opens the web app. On Windows, run the second line in PowerShell.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install.sh | sh
irm https://raw.githubusercontent.com/goat-si/goat-releases/main/install.ps1 | iex

A server-only machine

For a VPS or a spare Mac you reach from other devices. Installs the server as a background service and prints pairing links.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install-goat-server.sh | sh -s -- --tailscale
