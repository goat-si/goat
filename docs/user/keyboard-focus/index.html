Keyboard focus

The command palette keeps focus while open. Closing it returns focus to the composer. While the palette or model picker is open, number shortcuts select its entries instead of switching threads. Model shortcuts work in Settings as well as the composer. See Keybindings to customize these shortcuts.

If you return to typing while a terminal is starting, the composer keeps focus when the terminal becomes ready. Opening or switching to a terminal explicitly still focuses it.

In GOAT Bot, Tab also stops on each message. A focused or hovered message shows the time it was sent beside the bubble; the centered stamps mark days and long pauses.
