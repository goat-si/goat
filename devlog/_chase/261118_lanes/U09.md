# U09 · Mobile workspace navigation and layout

## C4 compatibility decisions (recorded before implementation)

- #42 (`a2edd281df2`). Mobile Android alert replacement only. The fork workspace picker and dirty-worktree confirmation already resolve to cancel via `onDismiss`. Older clients continue to speak the existing fork RPC to a newer server. New clients use the same RPC and negotiated fork capability with older servers. Replacing the chooser settles it as cancellation without selecting a workspace or sending a fork. Server-side refusal and the disabled Connect flow retain their current behavior. Upgrade and rollback carry the same installed auth and thread state; no migration is requested.
- #863 (`f6ef6c1f286`). iOS native workspace tabs only, with the installed binary build number presented separately in About. No server API or data format changes in either client/server pairing. Prewarm only the page a hidden tab will open with; absent, stale or disallowed selections get the existing route fallback. Rapid tab taps, disabled/re-enabled slots and a stale native selection acknowledgement must leave the active selection coherent. Keep GOAT's persisted workspace selections readable in both directions. Preserve the pinned native API unless native code is required and verified with a rebuilt binary; compatible native selection prevention is provided by t3.51.
