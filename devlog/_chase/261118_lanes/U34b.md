3. MODIFIED capacity and failure handling: the client always keeps the full captured PCM for the session (bounded by the same 300 s / 9.6 MB that today's batch recorder already holds). (a) If start reports busy, unsupported model, or the server lacks the capability, the session silently records in batch mode, exactly as today. (b) If the stream fails after start (slow worker/overflow, invalid server state, disconnect, model unload/reconfiguration, server shutdown), stop streaming, keep showing the preview, keep recording locally, and on Stop transcribe the full local recording through the existing batch path; that result replaces the preview. Show an error only if the batch transcription also fails, using today's batch error handling. (c) User Cancel discards everything as today. No "retry" UI and no unattached-text path for stream failure. Duration limit reached: finalize normally.
4. Native: APPROVED: use native.ts streaming begin/feed/finalize where the model supports it, probed at start; never dispose native state while inference is in flight; scoped finalizers release the worker and permit on cancel, disconnect, shutdown and model change; guardErrors/guardChild so a stream failure never reaches the process.
5. UI: APPROVED: recorder preview only; the draft is never changed before the final text; #931 owner/revision/selection fences and unattached behavior unchanged; #665/#714/#1099 unchanged; no continuously repainting animation.
6. Mobile: APPROVED unchanged (RN capture differs; it keeps the batch path, which a new server still serves). State that in the record and in docs only if docs already describe platform differences.
7. Setting: upstream 4247b5aa1a1's per-device switch chooses live transcription vs transcribing after Stop (no pause detection); the maintainer's "dictate after pause" means this switch. Add it only after streaming works: client-local per device, plain label (e.g. "Transcribe after I stop recording"), default off (live) when supported, hidden when the server lacks the capability or the selected model cannot stream. It changes only the streaming choice; recording behavior is otherwise identical.
8. Privacy: never log or trace audio bytes or transcript text; spans and logs carry ids, sizes and timings only.
9.
