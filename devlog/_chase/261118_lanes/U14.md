## C4 compatibility plan before implementation

- #838 / 83f35dac5c2. Wait for K8. Desktop download refreshes the selected feed under its action reservation. An ordinary install may supersede a retained download with a strictly newer offer, while an explicit prepared version stays exact. Recovery uses the version actually downloaded. A failed refresh must keep a usable prior offer, and no-offer, pause, restart drain denial and failed replacement must not trigger an unintended install. No IPC schema, backend readiness endpoint, or persisted state format changes. Older desktop/newer server and newer desktop/older server retain existing restart admission and the old HTTP readiness fallback. Existing pending/restart markers and updater rollback behavior remain valid.
- #969 / f68d9704fc9. Share GOAT's existing staged service preflight invocation with CLI runtime switches and add read-only database ledger compatibility to the target check. Use the selected GOAT home and GOAT launcher protocol 3. Old callers can still decode the same response, and a new updater can stage older protocol-3 runtimes that have preflight. Probe the ledger before allowing a switch to a legacy runtime whose preflight only checks the protocol. Missing/failed preflight, bad version/protocol/output, unsupported database and unreadable ledger fail before launchers or service state change. Keep cached runtime reuse, GOAT migration ID reconciliation, and service rollback semantics. Introduce no migration or persisted format.
