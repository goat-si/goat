## Coordinator C4 ruling (verbatim)

Coordinator C4 ruling, U59 #464 and #668: APPROVED with conditions.
Approved: the crash count persisted as optional continuation-intent data (absent on old records means today's behavior); old schemas decode the new optional field and the new code reads old records (byte-identical base-schema snapshot tests in both directions); the supporting recovery record kept through pruning; a planned update/restart resets the budget; live-turn adoption intact. #668: provider acceptance read from persisted evidence; unsent human prompts stay held (shown to the person, never auto-resent); only unattended work is resent in the same run, with a named bounded retry, durable outbox order and stop fences.
Conditions:
1. Crash budget: a named limit on consecutive crash recoveries per continuation. When it is exhausted, stop retrying and show a visible failed or parked state with a manual retry. No silent infinite restart loop. Planned restarts never count.
2. No double sends: a resend reuses the original command id, idempotency key and provider-turn identity wherever the provider or server dedupes. Where acceptance is unknown (the crash came after the write but before persisted acceptance), do NOT resend unattended work blindly unless the provider path is idempotent; otherwise park it as needing a decision. Show this in a test and say how each provider path decides.
3. Stop always wins: a Stop issued during a resend window prevents the resend, and a resend in flight is interrupted. Test it.
4. Migration: if you truly need one, migration 176 is reserved for U59. It must be additive only (new nullable columns or table; no rewrite of existing rows), registered in GOAT_MIGRATION_NAMES, with upgrade and rollback evidence (older binary after upgrade: the extra column is ignored) and a migration test. Prefer no migration if the optional JSON fields on existing records suffice.
Negative cases as you listed, plus: a crash during the resend itself; and two crashes in a row counting toward the budget. Record this ruling verbatim in U59.md.
