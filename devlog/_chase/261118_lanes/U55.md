## Coordinator rulings, verbatim

Coordinator C4 ruling, U55 #39/#904: APPROVED with these security conditions.
Approved: optional wire fields only, with byte-identical base-schema snapshot decode tests in both directions; GOAT theme IDs and settings authority kept; each new server setting classified in SETTINGS_ACCESS (with its agent/person reason); old clients ignore the additions; new clients tolerate absent fields.
CSS (#39):
- Parse with a real CSS parser (one already in the dependency tree; new dependency only via needs_input with name, version, license and size). Never use regex filtering.
- Allowlist properties and values instead of blocklisting. Scope every rule under the app's theme root by rewriting selectors; reject :root/html/body except the custom-property block that GOAT itself scopes. Reject @import, @font-face with remote sources, @namespace, expression(), behavior, -moz-binding, and any url() that is not a signed GOAT asset URL. Reject or strip CSS escapes that hide any of these.
- A named size limit on theme CSS, enforced on the server at save and import, and again on the client before applying.
- Applying the CSS must not repaint continuously (no animations or transitions added by theme CSS beyond what the allowlist permits).
Assets and backgrounds (#904):
- Signed URLs bind environment, asset identity, the published theme or background identity, and an expiry; signatures are compared in constant time. A saved theme sharing an ID with the published one gets no access to the published asset (test the same-ID saved/published collision).
- Images only, with a MIME and magic-byte check and a named size limit. SVG only if sanitized server-side (no script, foreignObject or external refs); otherwise reject it.
- Deny forged, expired, wrong-environment, traversal, unpublished and replaced-background requests with a 403/404 that leaks nothing.
- Who can publish: use the existing settings-write permission and scope, enforced on the server.
Tests: each rejection above, preview identity, reconnect, and an old client against a new server and vice versa. Record this ruling verbatim in U55.md.
