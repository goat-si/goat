## U02 review fix round 3

### Governing rule and pre-fix inventory

Only confirmed-unsent input may be replayed or re-sent. Delivered, inherited, unknown, legacy and ambiguous delivery never authorizes replay. An inbox item can be consumed only when the adapter actually submits the prompt containing it. Historical handoff context carries attribution and is never a live replacement prompt.

| Path | Evidence read before the fixes | Evidence owner | Confirmed unsent | Delivered | Ambiguous |
|---|---|---|---|---|---|
| Manual Resume | `manualContinuationDelivery` indexes persisted delivery in the newest steering epoch | Resumed run and manual ancestors | Replay the user payload or follow an unsent manual ancestor | Native Resume | Ask for an explicit message. Usage-limit synthetic prompts lack the existing restart-stub guard (P1-3). |
| Follow-up missed-input recovery | `missedTurnInputRuns` reads the same epoch classifier | Original failed or interrupted run | Eligible for text and image recovery | No retry | No retry. A replay by a different continuation run is invisible to the original run's index (P1-1). |
| Retry handoff | `prepareRetryHandoff` reads the missed-run set and exact current message IDs, filters covered history, and budgets recovered image IDs | Source attempt for input. Destination native thread for handoff coverage | Send only the matching missed request in history and its eligible images | Keep as history when appropriate | No missed-input retry. Same cross-run identity defect as follow-up recovery (P1-1). |
| Provider switch, direct or queued | The planner reads projected historical rows and excludes the selected manual replay by item ID | Selected source runs and latest steering attempts. Destination thread's previous context | May remain quoted history or the one separately confirmed live replay | History only | History only. A switch alone never issues the old prompt as live input. |
| Fresh-session recovery, including native fork fallback | Reads ordered history and handoff state. Excludes the selected live replay. Images come from the missed-run selector | Historical source items and the new destination identity | Historical context plus eligible confirmed-unsent images | History only | History only. Same source-identity requirement for replayable images (P1-1). |
