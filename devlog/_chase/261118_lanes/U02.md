A downgraded server reads the same projections and loses the new native-resume interpretation.
- #258. Add an optional server-owned first message to the existing create command. Old clients create and dispatch as before. All new first-message producers execute in-process alongside the matching server; clients do not require the optional field or a new event, and older clients understand the usual create and run events. External dispatch strips the field and server-owned provenance. A rejected first run rejects the whole create, and replay accepts both old split receipts and new atomic receipts without duplicating work or changing reused-thread delegation. Stored state consists of existing event types, so upgrade and rollback need no migration. Legacy split receipts keep their original deterministic dispatch ID. Reused threads, cloud launches and revocable Fleet confirmations use the existing split writes.
