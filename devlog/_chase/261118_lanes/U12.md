## Client observations

Web, desktop and mobile use the shared projections. A detached task stays running after launch, skipped child calls settle, and a requested shell wait holds the thread's working state until cleared or the shell exits. A background question remains answerable or dismissible after the parent finishes. A delivered report appears without eclipsing the preceding final answer. Code Mode pages appear once in the thread. Users can see 1.x context usage, 2.x limit warnings, cached and remote catalogs, Go usage, and a silently paused goal returning to idle.
