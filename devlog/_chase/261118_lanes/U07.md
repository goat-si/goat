### Compatibility and Rule 3

P2-1 is C4 because the Find RPC query decoder changes and server config advertises a new optional capability. A newer web or desktop client sends literal bounded queries only when the connected server advertises support; old servers receive the same trimmed query they receive today. Old web and desktop clients send trimmed queries and ignore the new optional config field. The current 200-character cap and rejection of blank input remain, and the existing RPC methods and authorization scopes apply. No persistent schema or cache format changes, so upgrade and rollback need no migration. Local and remote peers negotiate using their own server config. Mobile has no Find bar.

The accepted P2-1 behavior changes these existing `threadFindText.test.ts` expectations. Each removed character was the generated newline following `<br>`, previously counted as a space.
