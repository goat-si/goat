### Round 7 final bound

One DP covers the first 4,096 saved steps and up to 512 live items. At one byte per choice, the decision table is at most 2 MiB, with one rolling live-sized score row. It optimizes ordered match count, then exact matches, then earlier saved positions. Beyond step 4,096, the grouped tail keeps only text that neither equals nor extends a live item. The exact set and sorted non-overlapping prefix index are bounded by the original and reconciled forms of those 512 live items. This keeps the 512 individual backfill slots used for persisted child positions separate from the alignment cap.

The pinned upstream implementation uses substring membership in concatenated live text and appends a grouped remainder. No later commit in the pinned interval introduces an ordered Task projection matcher.

Older clients can read ordered history on refresh against newer servers. Newer clients against older servers still receive the older appended result. Existing position reservations take precedence, collisions use the ordinary allocator, and rollback requires no migration or conversion.
