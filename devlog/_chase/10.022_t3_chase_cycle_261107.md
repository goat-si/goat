## 방법

[020 수동 선별 사이클](./020_cycle_runbook.md#수동-선별-사이클)과 10.017-10.021을 따른다. take는 `cherry-pick -x`, adapt는 의미만 GOAT 코드에 재구현하고 커밋 본문에 `Upstream: <sha> (#PR)`, skip은 이유를 적는다. UI 레이아웃·스타일·디자인 토큰은 의미만 adapt한다. 010 영역과 부딪히면 GOAT 동작을 지킨다. 저장 데이터 수명, 권한 범위, 제품 방향을 정책 밖에서 바꾸는 것만 `⛔`로 올리고 결정 전에는 skip으로 둔다.

웨이브는 upstream 순서로 W1 #1-#77, W2 #78-#153이고, 웨이브 안에서 계열별로 묶는다. 묶음은 같은 base에서 병렬로 구현하고, 정확한 head에서 독립 리뷰해 PASS한 묶음만 `chase/t3-261107-combined`에 merge commit으로 합친다. 리뷰 4회차에도 FAIL인 행은 되돌리고, 그 행에 기대는 행까지 의존 폐쇄로 다시 판정한 뒤 남은 head를 다시 리뷰받는다.

모델: 사용자 지시(2026-11-07)대로 분류·구현·묶음 리뷰·integration 리뷰·최종 리뷰는 GOAT task(isolation worktree)의 gpt-6.1-terra(reasoning high, service tier default)가 하고 coordinator는 claude-opus-5-5다. 리뷰는 매번 구현 맥락이 없는 새 task다.

검증: 사용자 지시대로 로컬에서는 `check:changed`나 패키지 전체 스위트, 브라우저 테스트, 데스크톱 앱을 돌리지 않는다. 묶음은 고친 테스트 파일 단위 `vp test run <file>`와 정적 검사(`goat-rename --check`, `vp fmt`, `vp lint`), combined PR은 goat-ci 전체 실행이 정본이다.
