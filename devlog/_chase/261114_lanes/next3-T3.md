- Compatibility. An optional request flag on open/attach/restart enables a free-message error. A new server replies with the existing CWD stat error when the flag is absent. An older server's default Effect RPC payload decoder strips unknown struct fields, so a new client accepts the legacy reply and can show its existing message. Moved and unread worktrees must start no PTY; an unknown thread keeps its lookup error, denied calls keep their authorization error, and the new message omits the underlying exception. No stored rows change.
