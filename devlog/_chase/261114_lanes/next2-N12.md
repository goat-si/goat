## C4 compatibility (C22 status field, C25 capability)

- `savedProfilesUnreadable` (optional `Literal(true)`): a decoder without the field (the dev schema via mapFields) decodes a new payload; the new decoder decodes an old payload; `false` is rejected. PreviewAutomationStatus is decoded only server side (MCP), not by web or mobile.
- `serverBrowserStopLoading`: optional capability; an older server never sends it, so web and mobile keep Refresh/Reload; an older client ignores it and never sends stopLoading; an older server receiving stopLoading ignores it (dev ServerBrowser.ts viewer switch has no case). A newer web in an older desktop shell: bridge lacks stopLoading, so no Stop on desktop tabs. An older desktop app relaying Page.stopLoading from a newer server sends it to the CDP debuggee (at worst stops the app window's own load, which is finished).
