## 방법

사용자 결정으로 일괄 머지 대신 커밋마다 읽고 판정한다.

- **take**: `git cherry-pick -x`로 가져오고 이름·충돌을 손으로 푼다. 그 뒤 `node scripts/goat-rename.ts --apply`와 `--check`(exit 0).
- **adapt**: 의미만 GOAT 코드에 다시 구현하고 커밋 본문에 upstream sha를 적는다.
- **skip**: 가져오지 않는다. 이유를 적는다.
- UI 레이아웃·스타일·컴포넌트 구조·디자인 토큰·배치 변경은 따라가지 않는다. 그 변경이 담은 기능·버그 수정·접근성·상태 처리는 GOAT의 현재 UI에 맞게 adapt할 수 있다.
- 서버·프로토콜·provider·보안·버그 수정을 먼저 가져온다. [010](./010_fork_delta.md) 영역과 부딪히면 GOAT 동작을 지키고 이 표에 근거를 적는다.
- 의미 없는 리팩터(effect를 derive로 바꾸는 류)는 take의 전제이거나 실제 버그·비용을 줄일 때만 가져온다.

### 묶음별 공통 규칙

- take: `git cherry-pick -x <sha>`, 이름·충돌을 손으로 푼 뒤 `node scripts/goat-rename.ts --apply`와 `--check` exit 0.
- adapt: 의미만 GOAT 코드에 구현하고 커밋 본문에 `Upstream: <sha> (#PR)`을 적는다. UI 모양은 GOAT 현재 것을 유지한다.
