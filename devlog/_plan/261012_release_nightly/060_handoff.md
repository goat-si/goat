## Measurements

- M1 (keychain session): a gui-domain LaunchAgent (what `svc.sh` installs) sees the login keychain unlocked and reaches notarytool profiles; a Background session (SSH, LaunchDaemon) gets "User interaction is not allowed". FileVault is on, so an unplanned reboot needs a console unlock (which also logs in the user). Evidence: `evidence/m1_keychain_session.txt`, `evidence/m1b_preflight_sessions.txt`.
- M3 (Intel DMG on arm64): unsigned x64 DMG/ZIP build in 52 s; 30 of 31 Mach-O files carry x86_64 (the other is objc-js's unused arm64 prebuild); codesign signs x86_64 binaries here; nothing x64 runs without Rosetta. Evidence: `evidence/m3_x64_cross_build.md`.
- Dry run: arm64/x64 builds with builder payload reports, real darwin-arm64 CLI archive + smoke test + payload scan, assemble with SHA256SUMS, publish/prune plans against goat-releases (read-only). Unsigned DMGs are refused by assemble. Evidence: `evidence/dryrun_r3_chain.txt`, `evidence/m4_install_runner_dryrun_aqua.txt`.

## Remaining risks

- No real Developer ID signature, notarization, stapling or Gatekeeper assessment has run; the first macOS job is the first proof (fails closed if anything is missing).
- Windows, Linux arm64 and EPYC jobs have never executed; hosted runner availability (`windows-11-arm`) and costs are unmeasured.
- The Mac runner boundary depends on the advisory guard on the free plan (task 9). The guard pins prepare's resolve step by hash: editing that step requires updating the pin in .vite-hooks/goat-workflow-guard.mjs, and any expression string mentioning "secrets" outside publish is refused.
- Idle detection: a race remains between the last idle probe and stopping a backend or remote runtime; WSL backends always postpone automatic restart; legacy runtimes without the activity endpoint stay pending.
- A crashed recovery lock on a remote needs manual removal (the UI says which path).
- The SEA path rewrite relies on the checkout root appearing verbatim; the payload scan fails the build if any machine path survives.
- Pre-existing failures unrelated to this work, identical on origin/dev: `.github/scripts/*.test.cjs`, `apps/server/scripts/migrate-dev-db.test.ts`, two `apps/mobile/scripts` tests.
