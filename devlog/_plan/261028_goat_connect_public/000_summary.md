# 000 결론과 추천

조사일 2026-10-28. 근거는 010(현재 구조, path:line), 020(대안), 030(비용), 040(보안·남용·법적), 050(단계별 계획)에 있습니다.

## 질문 1. 지금 구조로 공개 다중 사용자 서비스가 가능한가

**초대제 베타까지는 가능하고, 무료 공개 가입은 지금 구조로는 안 됩니다.**

코드는 처음부터 한 운영자가 여러 사용자를 받는 relay로 짜여 있습니다. 모든 경로가 검증된 토큰의 사용자 ID만 쓰고, 환경 측 요청은 환경 키 서명으로 묶여 있어 코드 감사에서 남의 환경에 닿는 경로(IDOR)는 찾지 못했습니다. 사용자당 터널 제한, 웹훅 레이트 리밋, 터널 회수, Cloudflare API 429 공유 일시정지도 이미 있습니다. relay 테스트 277개가 통과합니다.

막히는 이유는 세 가지입니다.

1. **비용이 등록된 머신 수에 비례합니다.** Cloudflare는 2026-10-16에 Tunnels for Platforms를 내놓으며 계정당 터널 1,000개까지 무료, 이후 개당 월 $4.50으로 정했습니다. 현 설계는 머신마다 터널을 하나씩 만들고 잠든 노트북도 슬롯을 차지하므로, 사용자 1만 명이면 터널만 월 약 $63,000입니다. 새 Free DNS 존은 레코드 200개라 약 133명에서 막히고, 하위 도메인을 별도 존으로 쓰는 현 README 구성은 Enterprise 전용입니다.
2. **공개 가입에 필요한 통제가 없습니다.** 가입 통제는 Clerk 설정뿐이고, 터널 제한은 동시 요청에 뚫릴 수 있으며, 환경·기기 개수 상한, 링크·mint 레이트 리밋, 계정 삭제·정지가 없습니다.
3. **신뢰 구조가 무겁습니다.** Connect 계정 탈취는 그 사용자 머신에서의 코드 실행과 같고, relay 서명 키 하나가 연결된 모든 머신의 마스터 키입니다. 키 교체 경로도 없습니다. Cloudflare 약관의 프록시·VPN 제한에 GOAT Connect가 해당하는지도 확인되지 않았습니다.

## 질문 2. GOAT에 맞는가, 무엇을 바꿀 수 있는가

T3 구조는 "휴대폰이 각 머신에 직접 붙는다"는 전제입니다. GOAT는 이미 그 전제를 넘어섰습니다. 휴대폰은 허브 하나에 붙고 허브가 SSH·링크로 나머지 머신에 닿습니다. Tailscale 페어링, SSH, 서버 링크도 이미 있습니다. 그래서 바꿀 부분이 분명합니다.

- **Connect를 셋으로 나눕니다.** 모바일 푸시는 터널이 필요 없고, 이미 "publish-only" 링크 모드로 구현돼 있습니다. 공개 URL(웹훅·게스트 링크)과 어디서나 도달은 따로 풉니다.
- **관리형 터널은 사용자당 1개, 허브로만.** 기본값 3을 1로 낮추면 1,000명까지 터널 비용이 $0입니다.
- **공개 단계의 도달은 Durable Object WebSocket relay + 종단 간 암호화.** 양쪽이 바깥으로만 연결하므로 터널·DNS 프로비저닝이 없고, 비용은 실제 사용 시간에 비례합니다(가정상 1만 명 약 $3,500/월). 페어링 키로 내용을 암호화하면 relay 서명 키가 마스터 키 역할을 하지 않게 됩니다.
- **웹훅은 relay가 받아 두고 호스트가 가져가게 합니다.** 기존 오프라인 보관 구조의 방향만 바꾸면 공개 URL에 터널이 필요 없습니다.
- **Clerk과 Postgres는 유지합니다.** 1만 명이어도 Clerk Pro $25, DB 0.3~0.7GB 수준입니다. 비용을 정하는 것은 인증이나 DB가 아니라 도달 방식입니다. DB만 `PS_80` + 레플리카 2에서 작은 SKU로 줄입니다.
- **T3 흔적은 대부분 의도된 호환 코드입니다.** 공개 전에 고칠 것은 네이티브 로그인 설정 문서(Android Clerk 콜백, 데스크톱 패스키 App ID가 `com.t3tools.t3code` 기준)와 사용자 문서의 "T3 Connect" 표기입니다. 실제 앱 ID는 이미 `si.goat.*`입니다.

## 추천

## 사람이 결정할 것

1. 공개 단계에서 Connect를 무료로 둘지, 유료 단계를 둘지.
2. 도달 방향: 베타는 허브 터널 1개, 공개는 DO relay + E2EE. 이 방향에 동의하는지.
3. 운영 주체(개인·사업자)와 공개 연락처, 개인정보처리방침·약관 작성 방식(직접 또는 전문가 검토).
4. 도메인 두 개(서비스용, 터널 전용 별도 apex) 등록.
5. Cloudflare에 약관 해석 문의 여부와 주체.
6. 베타 인원 규모와 장애·보안 대응 담당자.
7. Clerk Pro($25/월) 결제 시점.

## 이 결론의 한계

비용은 공개 가격과 가정으로 계산한 추정이며 실제 relay 사용량을 잰 값이 없습니다. 터널 제한 경쟁 조건은 정적 분석이고 재현하지 않았습니다. Cloudflare 약관 적용, Clerk device grant의 정식 지원 여부, 각 위탁사의 처리 국가는 확인하지 못했습니다. 법적 항목은 조사 결과이며 법률 자문이 아닙니다.
