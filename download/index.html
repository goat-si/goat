Download GOAT

Every build comes from the goat-si/goat-releases repository on GitHub. The desktop app updates itself.

Finding the newest build on GitHub.

macOS

  • Apple silicon.dmg
  • Intel.dmg

Intel Macs get the desktop app; the goat command is not built for them.

Windows

  • x64.exe
  • ARM64.exe

Linux

  • x86_64AppImage
  • ARM64AppImage
  • Debian and Ubuntu, amd64.deb
  • Debian and Ubuntu, arm64.deb

Install a .deb with sudo apt install ./<file>.deb. It asks for your password to install each update.

Install GOAT

The goat command

Starts the server and opens the web app. On Windows, run the second line in PowerShell.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install.sh | sh
irm https://raw.githubusercontent.com/goat-si/goat-releases/main/install.ps1 | iex

A server-only machine

For a VPS or a spare Mac you reach from other devices. Installs the server as a background service and prints pairing links.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install-goat-server.sh | sh -s -- --tailscale

Phone and tablet

The GOAT app for iPhone, iPad and Android is in development and is not in the App Store or Google Play yet. iPhone and iPad builds come through TestFlight, which is invite-only for now, or you can build the app from source. Until then, pair your phone's browser with an environment.

The T3 Code app in the stores belongs to the project GOAT is forked from. It is not GOAT and cannot connect to a GOAT server.
