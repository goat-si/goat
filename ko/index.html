내 모든 머신에서, 내 코딩 에이전트를.

GOAT는 이미 쓰고 있는 Claude Code, Codex, Cursor 같은 에이전트를 노트북, 집 데스크톱, SSH 서버, 클라우드 머신에서 실행해요. 그리고 데스크톱 앱, 브라우저, 휴대폰 어디서든 전부 조종할 수 있어요.

GOAT 다운로드가이드 읽기

MIT 라이선스로 무료 공개된 오픈 소스예요. macOS, Windows, Linux에서 쓸 수 있어요.

머신마다 하나의 환경

작업하는 머신마다 GOAT 서버가 돌아가요. 그 서버와 서버가 가진 상태(프로젝트, 스레드, 프로바이더 로그인, 메모리)를 합쳐 환경이라고 불러요. 데스크톱 앱, 브라우저, 휴대폰은 원하는 만큼 여러 환경에 연결할 수 있고, 환경끼리도 서로 닿을 수 있어요.

원격 접속 가이드
SSH 호스트
Settings → Connections에서 호스트를 추가하면 처음 쓸 때 호스트가 직접 GOAT 런타임을 내려받아요. Boat 클라우드 머신도 다른 SSH 호스트와 똑같이 동작해요.
연결된 GOAT 서버
이미 운영 중인 GOAT 서버를 페어링 링크로 연결하면, 에이전트가 그 서버에서 스레드를 시작하고 읽고 메시지를 보낼 수 있어요.
WSL
Windows에서는 WSL 배포판이 자체 환경을 갖고, 그 안에 설치한 프로바이더 CLI를 써요.
다른 화면들
휴대폰이나 다른 브라우저를 직접, 같은 로컬 네트워크에서, 또는 Tailscale로 페어링하세요.

한 머신에서 시작해 다른 머신에서 마무리

GOAT의 에이전트는 머신을 넘나들고, 내 작업도 함께 움직여요.

  1. 노트북에서 스레드 시작

    프로젝트와 프로바이더를 고르세요. 에이전트가 로컬 Git 체크아웃에서 일하면 턴마다 체크포인트가 남아서, 무엇이 바뀌었는지 정확히 확인하고 되돌릴 수 있어요.

  2. 더 큰 머신으로 옮기기

    커밋하지 않은 변경까지 그대로 SSH 호스트로 스레드를 옮기거나, 에이전트가 그곳에서 스레드나 워크트리를 시작하고 결과를 기다리게 하세요.

  3. 어디서든 이어 보기

    그 환경과 페어링한 휴대폰이나 다른 브라우저에서 같은 스레드를 열고, 에이전트가 기다릴 때 답하세요.

  4. 브랜치 가져오기

    SSH 워크트리의 브랜치를 이 기기의 저장소로 가져와요. 지금 체크아웃한 브랜치와 작업 파일은 그대로예요.

GOAT가 더하는 것

  • GOAT Bot

    프로젝트에 묶이지 않은 상시 대화 창이에요. 일을 부탁하면 알맞은 프로젝트와 머신에 코딩 스레드를 시작하고 결과를 알려 줘요. Slack에서도 답하고, 서버가 Mac에서 돌면 iMessage로도 답해요.

    가이드 읽기: GOAT Bot

  • Fleet

    연결된 모든 머신과 그 위에서 일하는 에이전트를 한 화면에서 보고, 실행 중이거나 나를 기다리는 스레드 수를 확인해요. Fleet 목표는 정한 조건이 충족될 때까지 작업자를 계속 띄워요.

    가이드 읽기: Fleet

  • 메모리

    끝난 대화가 전체 프로젝트, 한 프로젝트, 한 스레드 범위의 메모리가 돼요. Codex, Claude, OMO의 메모리를 가져오고, 허브를 통해 기기끼리 공유할 수 있어요.

    가이드 읽기: 메모리

  • 오케스트레이션 도구

    GOAT MCP 서버는 에이전트에게 스레드를 띄우고 지켜보고, 시작한 스레드에 결과를 보고하는 도구를 줘요. Claude Code, Codex, ChatGPT 같은 외부 에이전트도 같은 서버에 연결할 수 있어요.

    가이드 읽기: 오케스트레이션 도구

  • 컴퓨터, 브라우저, 기기

    에이전트가 GOAT를 실행하는 컴퓨터의 앱을 내 커서를 뺏지 않고 써요. 데스크톱 앱에는 스레드마다 브라우저 패널이 있고, Device 패널에서는 에이전트가 다루는 iOS 시뮬레이터나 Android 에뮬레이터를 볼 수 있어요.

    가이드 읽기: 컴퓨터, 브라우저, 기기

  • 소스 관리와 풀 리퀘스트

    저장소를 클론하고 게시하고, 풀 리퀘스트를 열고, 턴마다 바뀐 내용만 리뷰해요. GitHub, GitLab, Forgejo, Gitea, Bitbucket, Azure DevOps, GitCafe를 지원해요.

    가이드 읽기: 소스 관리와 풀 리퀘스트

  • 시각적 답변

    차트나 표, 다이어그램을 부탁하면 에이전트가 스레드 안에 샌드박스 페이지로 답해요. 모든 프로바이더에서, 웹과 데스크톱, 모바일 모두에서 동작해요.

    가이드 읽기: 시각적 답변

공개적으로 만드는 오픈 소스

GOAT는 MIT 라이선스로 공개 저장소에서 개발하고, 작업은 GitHub 이슈와 풀 리퀘스트로 추적해요. T3 Code의 포크로 시작해 이벤트 소싱 코어를 그대로 쓰고, 지금도 업스트림 변경을 합치고 있어요.

GOAT 설치

데스크톱 앱은 스스로 업데이트해요. goat 설치 스크립트는 GOAT_CHANNEL=stable을 설정하지 않으면 Nightly 빌드를 따라가요.

데스크톱 앱

macOS, Windows, Linux용이에요. 서버와 goat 명령이 함께 들어 있어서, 다른 화면이 연결할 환경을 직접 띄울 수도 있어요.

다운로드 고르기

goat 명령

서버를 시작하고 웹 앱을 열어요. Windows에서는 두 번째 줄을 PowerShell에서 실행하세요.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install.sh | sh
irm https://raw.githubusercontent.com/goat-si/goat-releases/main/install.ps1 | iex

서버 전용 머신

다른 기기에서 접속하는 VPS나 남는 Mac에 쓰세요. 서버를 백그라운드 서비스로 설치하고 페어링 링크를 출력해요.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install-goat-server.sh | sh -s -- --tailscale
