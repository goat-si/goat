GOAT 다운로드

모든 빌드는 GitHub의 goat-si/goat-releases 저장소에서 받아요. 데스크톱 앱은 스스로 업데이트해요.

GitHub에서 최신 빌드를 찾고 있어요.

macOS

  • Apple 실리콘.dmg
  • Intel.dmg

Intel Mac에서는 데스크톱 앱을 쓸 수 있지만 goat 명령은 제공되지 않아요.

Windows

  • x64.exe
  • ARM64.exe

Linux

  • x86_64AppImage
  • ARM64AppImage
  • Debian·Ubuntu amd64.deb
  • Debian·Ubuntu arm64.deb

.deb는 sudo apt install ./<file>.deb로 설치하세요. 업데이트할 때마다 비밀번호를 물어봐요.

모든 빌드와 체크섬Nightly 빌드설치 가이드

GOAT 설치

goat 명령

서버를 시작하고 웹 앱을 열어요. Windows에서는 두 번째 줄을 PowerShell에서 실행하세요.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install.sh | sh
irm https://raw.githubusercontent.com/goat-si/goat-releases/main/install.ps1 | iex

서버 전용 머신

다른 기기에서 접속하는 VPS나 남는 Mac에 쓰세요. 서버를 백그라운드 서비스로 설치하고 페어링 링크를 출력해요.

curl -fsSL https://raw.githubusercontent.com/goat-si/goat-releases/main/install-goat-server.sh | sh -s -- --tailscale

휴대폰과 태블릿

iPhone, iPad, Android용 GOAT 앱은 개발 중이고 아직 App Store와 Google Play에 없어요. iPhone과 iPad 빌드는 지금은 초대 전용인 TestFlight로 받거나 소스에서 직접 빌드할 수 있어요. 그전까지는 휴대폰 브라우저를 환경과 페어링해서 쓰세요.

스토어에 있는 T3 Code 앱은 GOAT가 포크한 원래 프로젝트의 앱이에요. GOAT가 아니고 GOAT 서버에 연결할 수 없어요.
